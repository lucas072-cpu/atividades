# ONG Esperança

Projeto front-end desenvolvido para a **ONG Esperança**, com o objetivo de divulgar projetos sociais, incentivar o voluntariado e facilitar o contato com a organização.

PROJETO: https://lucas072-cpu.github.io/atividades/

## 🚀 Funcionalidades

- Página inicial;
- Projetos sociais;
- Área de voluntariado e doações;
- Formulário de cadastro;
- Validação de formulário;
- Armazenamento com `localStorage`;
- Menu responsivo;
- Navegação SPA sem recarregamento da página.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Single-SPA 5.9.3
- Git e GitHub

## 📁 Estrutura

```text
atividades/
├── css/
├── js/
├── pages/
├── assets/
└── index.html
```

## ♿ Acessibilidade e responsividade

Foram aplicadas práticas da **WCAG 2.1**, incluindo HTML semântico, `alt` em imagens, `label` nos formulários, navegação por teclado e foco visível.

O layout utiliza **Flexbox, CSS Grid e media queries** para adaptação a diferentes dispositivos.

## ▶️ Execução

Não são necessárias dependências externas. Basta clonar o repositório e abrir o `index.html` no navegador ou utilizar o **Live Server** no Visual Studio Code.

```bash
git clone https://github.com/lucas072-cpu/atividades.git
```

## 🔀 Versionamento

O projeto utiliza **Git/GitHub** para controle de versões, com commits realizados durante o desenvolvimento. A organização segue conceitos do **GitFlow**, utilizando `main`, `develop` e `feature/*`.

Também é utilizado **Versionamento Semântico (SemVer)**, no formato `MAJOR.MINOR.PATCH`.
